## 🎯 Learning Objectives

By completing this challenge, you should be able to:

- Store multiple values in a Python list.
- Access and process elements in a list.

- Compare values using conditional logic.
- Calculate an average using basic arithmetic.
- Explain the logic behind your solution.

## 📝 Problem Statement

You are given the following list of student marks:

```python
marks = [72, 45, 89, 63, 51, 94, 38]
```

Your task is to analyse the marks and determine:

1. The highest mark.
2. The lowest mark.
3. The average mark.

### ⚠️ Restrictions

**You must not use the following built-in functions:**

- `max()`
- `min()`
- `sum()`

You are expected to work through the values yourself using your knowledge of Python fundamentals.

## 📋 Requirements

Your program must:

1. Use the provided list of marks.
2. Determine the highest mark without using `max()`.
3. Determine the lowest mark without using `min()`.
4. Calculate the average without using `sum()`.
5. Display all three results clearly.
