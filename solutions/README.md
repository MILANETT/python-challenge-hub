# 📚 Reference Solutions

This directory contains reviewed reference solutions for completed Python challenges.

Its purpose is to help members compare approaches, understand implementation decisions, learn from mistakes, and strengthen their programming skills.

## 1. Organization

Reference solutions are organized by challenge ID.

Example structure:

- `PY001/` — Reference solution for PY001
- `PY002/` — Reference solution for PY002
- `PY003/` — Reference solution for PY003

Each challenge's solutions directory may contain:

- A clearly named Python solution file.
- Explanations of the logic and important implementation decisions.
- Notes on alternative approaches, edge cases, or common mistakes where useful.

Solutions should be easy to navigate and clearly associated with their corresponding challenge.

## 2. Publication Process

Reference solutions follow this sequence:

1. The challenge deadline passes.
2. Members participate in the designated group discussion.
3. The proposed reference solution is reviewed.
4. The reviewed solution is published when approved.

**A passed deadline alone does not authorize immediate publication.** The discussion and review stages must also be respected.

## 3. Review Standards

Before publication, a reference solution should:

- Satisfy the challenge requirements.
- Produce correct results for relevant test cases.
- Handle required edge cases appropriately.
- Follow any restrictions specified in the challenge.
- Be readable and reasonably well organized.
- Explain important reasoning and implementation decisions where useful.

Where multiple valid approaches exist, reference materials should acknowledge meaningful alternatives rather than imply that only one implementation is correct.

## 4. Protecting Member Work

- Do not publish reference solutions before the required discussion and review.
- Do not copy members' private submissions into this directory without permission.
- Do not use this directory to collect unfinished or private challenge submissions.
- Keep personal submissions within the designated submission workflow.

## 5. Learning, Not Memorization

Reference solutions are learning resources, not answers to memorize.

Members are encouraged to compare their own approaches with the references, investigate differences, test alternative implementations, and identify what they can improve.

A different solution may be equally valid if it satisfies the challenge requirements and follows its restrictions.

**Understand the reasoning. Compare the approaches. Learn something you can use in the next challenge.**
