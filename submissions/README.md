# Python Challenge Submissions

This directory stores members' individual Python challenge submissions.

## Submission Rules

1. Attempt each challenge independently before viewing other members' solutions.
2. Save your completed work as a `.py` file.
3. Do not upload solutions until the agreed solution-release condition has been met.
4. Follow the folder structure and naming conventions below.
5. Ensure your submission follows the challenge instructions, including any required explanations or reflections.

## Folder Structure

Each challenge has its own folder.

```text
submissions/
├── README.md
├── PY001/
│   ├── github-username-1.py
│   └── github-username-2.py
└── PY002/
    ├── github-username-1.py
    └── github-username-2.py
```

Replace the example usernames with your own GitHub username.

## File Naming

Use this format:

`your-github-username.py`

For example, a member with the username `exampleuser` would submit their PY001 solution as:

`submissions/PY001/exampleuser.py`

## Uploading Your Work

After the solution-release condition has been met:

1. Open the relevant challenge folder in this repository.
2. Select **Add file → Upload files**.
3. Upload your completed Python file.
4. Enter a clear commit message, such as `Add PY001 submission`.
5. Follow the repository's contribution workflow to complete the submission.

## Important

This repository is public. Uploaded files can be viewed by anyone, not just group members. Never upload unfinished solutions or reveal answers before the agreed release condition.
