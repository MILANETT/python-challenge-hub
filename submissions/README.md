# Python Challenge Submissions

This directory stores members' individual Python challenge submissions.

## Submission Rules

1. Attempt each challenge independently before viewing other members' solutions.
2. Submit your work as either a Python script (`.py`) or a Jupyter Notebook (`.ipynb`).
3. Do not upload solutions until the agreed solution-release condition has been met.
4. Follow the folder structure and file-naming conventions below.
5. Include any explanations, reflections, or AI-use disclosures required by the challenge.
6. Ensure your submission contains your own work and follows the group's challenge rules.

## Folder Structure

Each challenge has its own folder.

```text
submissions/
├── README.md
├── PY001/
│   ├── githubusername.py
│   └── anotherusername.ipynb
└── PY002/
    ├── githubusername.ipynb
    └── anotherusername.py
```

## File Naming

Use your GitHub username as the filename, followed by the appropriate extension:

- Python script: `yourusername.py`
- Jupyter Notebook: `yourusername.ipynb`

For example, if your GitHub username is `exampleuser`, your PY001 submission could be:

`submissions/PY001/exampleuser.py`

or

`submissions/PY001/exampleuser.ipynb`

Use one primary submission file per challenge unless the challenge instructions explicitly require additional files.

## Uploading Your Work

After the agreed solution-release condition has been met:

1. Open the relevant challenge folder in this repository.
2. Select **Add file → Upload files**.
3. Upload your completed `.py` or `.ipynb` file.
4. Enter a clear commit message, such as `Add PY001 submission`.
5. Follow the repository's contribution workflow to complete the submission.

## Jupyter Notebook Guidelines

- Keep code cells organized and runnable in order.
- Include explanations in Markdown cells where appropriate or required.
- Remove unnecessary outputs before uploading.
- Do not include passwords, access tokens, private data, or other sensitive information.

## Important: Public Repository

This repository is public. Anyone can view files uploaded here, including submissions. Do not upload unfinished solutions or reveal answers before the agreed release condition has been met.
