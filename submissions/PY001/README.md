# PY001 — Submissions

This folder contains members' individual submissions for PY001.

## Submission Instructions

- Submit either a `.py` Python script or an `.ipynb` Jupyter Notebook.
- Name your file using your GitHub username, followed by the appropriate extension.
- Examples: `yourusername.py` or `yourusername.ipynb`.
- Upload your submission only after the group's agreed solution-release condition has been met.
- Follow all instructions in the original PY001 challenge.
- Submit your own work and disclose AI assistance as required by the challenge rules.

## Important

This repository is public. Uploaded submissions can be viewed by anyone. Do not upload solutions before the agreed release condition.
