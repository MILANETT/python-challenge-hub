# PY003 — Submissions

This folder contains members' individual submissions for PY003.

## Submission Instructions

- Submit either a Python script (`.py`) or a Jupyter Notebook (`.ipynb`).
- Name your file using your GitHub username, followed by the appropriate extension.
- Examples: `yourusername.py` or `yourusername.ipynb`.
- Upload your work only after the group's agreed solution-release condition has been met.
- Follow all instructions in the original PY003 challenge.
- Include required debugging comments and any other explanations specified in the challenge.
- Disclose AI assistance as required by the challenge rules.
- Audio explanations of your code may also be submitted, provided they follow the group's agreed audio format and file-size limits.

## Important

This repository is public. Uploaded submissions and audio explanations can be viewed by anyone. Do not upload solutions before the agreed release condition. Do not include sensitive personal information in your code, notebooks, or recordings.
