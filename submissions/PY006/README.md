# PY006 — Submissions

This folder contains members' individual submissions for PY006.

## Submission Instructions

- Submit either a Python script (`.py`) or a Jupyter Notebook (`.ipynb`).
- Name your file using your GitHub username, followed by the appropriate extension.
- Examples: `yourusername.py` or `yourusername.ipynb`.
- Upload your work only after the group's agreed solution-release condition has been met.
- Follow all instructions in the original PY006 challenge.
- Include any required explanations, docstrings, reflections, and AI-use disclosures specified by the challenge.
- You may also submit an audio explanation of your code using the group's agreed audio format and file-size limits.

## Important

This repository is public. Anyone can view uploaded submissions and audio explanations. Do not upload solutions before the agreed release condition, and never include sensitive personal information.
