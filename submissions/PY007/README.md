# PY007 — Submissions

This folder contains members' individual submissions for PY007: **Inside and Outside — Understanding Scope**.

## Submission Instructions

- Submit either a Python script (`.py`) or a Jupyter Notebook (`.ipynb`).
- Create a folder named with your GitHub username, then place your submission file inside it.
- Use a clear filename, such as `PY007.py` or `PY007.ipynb`.
- Follow all instructions in the original PY007 challenge.
- Include any required explanations of your scope experiments and conclusions.
- If you used AI or online help after the challenge's permitted independent-attempt period, include the disclosure required by the challenge instructions.
- Upload your work only when the group’s agreed submission/release process allows it.
