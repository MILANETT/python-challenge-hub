# PY011 — Submissions

This folder contains members' individual submissions for **PY011 — The Learning Analytics Team**.

## Submission instructions

- Create a folder named with your GitHub username.
- Put your Python program and any required testing evidence inside that folder.
- Use a clear filename, such as `PY011.py`.
- Follow the full requirements in the [PY011 challenge](../../challenges/PY011/README.md).
- Use the supplied member records as the starting data.
- Include comments where they help explain important decisions or non-obvious logic.
- Disclose AI or online assistance as required by the group's rules.
- Follow the group's agreed submission and release process; do not publish unfinished work or solutions before permitted.

## Suggested structure

```text
submissions/
└── PY011/
    ├── README.md
    └── your-github-username/
        ├── PY011.py
        └── testing-evidence.md
```

## Public repository reminder

This repository is public. Do not include passwords, access tokens, or sensitive personal information in your submission.
