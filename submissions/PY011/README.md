# PY011 Submissions

Submit your completed PY011 challenge in this folder.

## How to submit

1. Create a folder using your GitHub username.
2. Place your completed Python file inside that folder. Name it `PY011.py`.
3. You may include a short `README.md` or `testing-evidence.md` if you want to explain your approach or show your tests.
4. Submit your work through a pull request targeting `main`, following the group's usual submission process.

## Folder structure

```text
submissions/
└── PY011/
    ├── README.md
    └── your-github-username/
        ├── PY011.py
        └── testing-evidence.md
```

## Before submitting

- Make sure your code addresses all five questions in the [PY011 challenge](../../challenges/PY011/README.md).
- Use the supplied `members` records as your starting data.
- Keep your code readable and add comments where they help explain important decisions.
- If you used AI, online references, or help from another person, disclose that in your submission as required by the group's rules.
- Do not include passwords, access tokens, or other sensitive personal information.

Each participant should submit their own work in their own username folder.
