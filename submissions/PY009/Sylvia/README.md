### Equipment Desk Management System

This program manages **equipment inventory and borrowing requests** for a campus equipment desk.
It allows users to 
add equipment
register borrowing requests
issue available equipment
return borrowed equipment
and cancel pending requests.

The program uses **lists and dictionaries** to store inventory and request records. 
It also includes functions for searching records, validating information,
managing equipment availability, and generating inventory reports. 
A menu-driven interface allows users to perform multiple operations during one session.
