# PY009 — Submissions

This folder contains members' individual submissions for **PY009 — The Equipment Desk**.

## Submission instructions

- Create a folder named with your GitHub username.
- Put your Python program and any required testing evidence inside that folder.
- Use a clear filename, such as `PY009.py`.
- Follow the full requirements and submission rules in [the PY009 challenge](../../challenges/PY009/README.md).
- Use only built-in Python features and concepts covered in PY001–PY008, as specified by the challenge.
- Include comments that explain important decisions and non-obvious logic.
- Disclose AI or online assistance as required by the challenge instructions.
- Follow the group's agreed submission and release process; do not publish unfinished work or solutions before permitted.

## Suggested structure

```text
submissions/
└── PY009/
    ├── README.md
    └── your-github-username/
        ├── PY009.py
        └── testing-evidence.md
```

The testing evidence can be a short Markdown file or another format accepted by the group. Include examples of normal operations and rejected actions, especially inventory limits, invalid quantities, duplicate IDs, returns, and cancellations.

## Public repository reminder

This repository is public. Do not include passwords, access tokens, or sensitive personal information in your submission.
