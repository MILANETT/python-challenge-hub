# PY008 — Submissions

This folder contains individual submissions for PY008: **The Function Toolkit: Flexible, Composable, and Clever**.

## Submission instructions

- Submit a Python script (`.py`) or Jupyter Notebook (`.ipynb`).
- Create a folder named with your GitHub username and place your file inside it.
- Use a clear filename, such as `PY008.py` or `PY008.ipynb`.
- Follow the full instructions in [the PY008 challenge](../../challenges/PY008/README.md).
- Ensure the submission includes the required functions, menu, tests/evidence, docstrings, and explanatory comments.
- Include an AI-assistance disclosure if required by the challenge.
- Upload only when the group's agreed submission/release process allows it.

## Suggested structure

```text
submissions/
└── PY008/
    ├── README.md
    └── your-github-username/
        └── PY008.py
```
