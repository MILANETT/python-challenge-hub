# PY002 — Submissions

This folder contains members' individual submissions for PY002.

## Submission Instructions

- Submit either a Python script (`.py`) or a Jupyter Notebook (`.ipynb`).
- Name your file using your GitHub username, followed by the appropriate extension.
- Examples: `yourusername.py` or `yourusername.ipynb`.
- Upload your work only after the group's agreed solution-release condition has been met.
- Follow all instructions in the original PY002 challenge.
- Include any required explanations and disclose AI assistance as required by the challenge rules.

## Important

This repository is public. Uploaded submissions can be viewed by anyone. Do not upload solutions before the agreed release condition.
